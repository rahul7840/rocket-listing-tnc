# Rocket Listing — Privacy Policy & Terms

Static privacy policy and terms & conditions page for the [Rocket Listing](../ext-reacoder)
Chrome extension. Plain HTML/CSS/JS, no build step — served directly via GitHub Pages.

## Local preview

Just open `index.html` in a browser, or serve it:

```bash
npx serve .
```

## Deploy

Pushing to `main` publishes automatically via GitHub Pages (see `.github/workflows/pages.yml`).
Live URL: `https://<your-username>.github.io/rocket-listing-tnc/`
